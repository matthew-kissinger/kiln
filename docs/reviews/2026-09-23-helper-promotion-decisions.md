# Additional helper and recipe decisions

The current decision is to retain freeform construction and defer additional
shed/hip roof factories and segmented-primitive wrappers. Existing shared fixes
address observed failures; adding more names without a demonstrated need would
increase discovery cost. This is R06's final checkout decision, reviewed against
all 36 main authorings, 12 held-outs and the completed Native13 baseline and edits.

The retained architecture expansion gate has eight fixed shed/hip cases per arm.
Both the existing construction and candidate factories pass all eight, including
both UV cases. These are authored deterministic fixtures, not an agent experiment:
zero measured improvement here does not prove that a helper could never benefit a
model. Keep those candidates test-only until a fresh failure demonstrates a gap.
No historical gallery repair or quality acceptance is involved.

A current compiled-CLI probe also establishes that per-axis segmentation is
already available through the public THREE constructor. An ordinary box exports
12 triangles and 24 position vertices; a box with 24 height divisions exports
196 triangles and 208 position vertices. Applying the shared `bend` operation
preserves that topology and all three outputs have zero glTF validator errors or
warnings. This proves availability and export, not model uptake or visual quality.

Discovery already advises supplying enough segments for deformation. A thin
constructor wrapper is not warranted by the observed failures.

The campaign has warranted shared improvements: multiple wall openings,
frame-aware placement, assembly replication, UV projection, joined-frame and
wheel-support guidance, surface measurement, animation sampling and protected
part comparisons. Those changes have their own bounded evidence in the
[campaign report](2026-09-22-opencode-main-campaign.md). Main30's obstructed
gateway, Main31's unsupported walking feet and Main32's unused tear parameter
remain construction or inspection failures. Another shape alias would not, by
itself, prevent them. Main33's custom rounded profile is usable; this single case
does not establish demand for another public profile factory.

Reopen a promotion only when future fresh trials show a repeated need
that current documented composition cannot address cleanly. Measure the proposed
helper against that failure and preserve editable parts, attributes and arbitrary
placement. Do not require catalog growth to call this upgrade successful.

## C08 frame-attachment decision

Defer the public frame-attachment candidate. The retained external experiment
matches manual placement and GLB export in all six wheel/roof/bay cases, with
maximum matrix/alignment/export error below 1.8e-15. Its counterexamples show why
promotion needs more than correct transform algebra: inherited scale doubles one
hardware axis, relative shear is rejected, and a wrong physical datum leaves a
4 mm gap despite exact frame agreement. No authoring advantage was established.
The candidate stays external; shared lossless TRS validation remains implemented.

Supported construction uses a named local root, explicit shared attachment points
and ordinary parent-local transforms. Use the existing joined-frame recipe where
it helps, then measure each intended interface and required clearance. Main35's
fresh track/fork edits preserve the protected assembly and detect a rack-support
gap through those shared tools. That is positive evidence for the existing route,
not a controlled comparison with the candidate or proof of physical mating.

C08's requested adopt/defer decision is complete on this bounded evidence. Reopen
only for a demonstrated case that the existing construction cannot handle cleanly;
R06's final trace review found no additional promotion justified. This does not leave an
unannounced extra public API or another speculative implementation lane.
Receipt: `C:/Users/Mattm/X/kiln-dogfood/unification-2026-09-22/frame-attachment/receipt.json`;
reproduction: `../frame-attachment-experiment.ts` in that evidence root.

Final held-out findings warranted shared repair feedback and geometry guidance,
not more shape factories. Custom-grid singularities, normal recomputation and
missing XYZ components now have bounded guidance/diagnostics. Misrouted perimeter
bars, omitted mounts and partial inspection remain visible quality failures.
Native13 completed a curved textured rail and interchangeable supports through
existing sweep, material, placement and inspection tools. These observations do
not establish perfect model use; they provide no measured case for another roof,
boat or bracket-specific API in this pass.
