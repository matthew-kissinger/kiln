## Workflow context boundary

Strands receives its native bootstrap and lazily activated native workflow.

explicitly declared technical reference files through a bounded reader. Mixed CLI

and selected technical documents have one maintained source. Custom host-selected
native skills still work; the host owns their relevance.

refinement through the SDK, refusal of workspace-only reference reads, and missing
reference failure. These scripted runs validate wiring and context separation;
they do not establish improved live model behavior. Existing provider trials
predate this context change. No additional metered Strands run is scheduled.

## Fresh AGY dogfood

All runs used AGY 1.2.3, `gemini-3.8-flash-high`, high effort and no artificial
turn/time cap. Each baseline used a fresh home/profile and project. OS keyring
authentication was retained; no user skills, MCP configuration or previous
project history was copied. This is context isolation, not an OS sandbox. The
blind setup read the distributed installer and AGY's built-in setup references;
no `src/`, gallery examples or audit reports were read.

| Stage | Agent-response steps | Outcome |
| --- | ---: | --- |
| Blind local installation/setup | 54 | Installed candidate, generated workspace, rendered three-part test |
| New-session MCP verification | 11 | Correct installation identity; actual MCP GPU render and image read |
| Wizard hat authoring | 70 | Source, GLB, six-view sheet and saved revision |
| Hat patch refinement | 22 | Only patch/stitches changed; six other nodes unchanged |
| Floating island authoring | 107 | Source, GLB, six-view sheet and saved revision |
| Island ramp refinement | 28 | Only ramp changed; fifteen other nodes unchanged |

These are trace-level agent-response steps, not AGY's outer `num_turns` field
(which reports one or two for these conversations). They are not a matched-model
comparison against Strands. Much of AGY's work consists of reading offloaded tool
results and images: the two authorings used 42 and 44 `view_file` calls. Both
used 13 Discovery calls. More catalog prose in the starting prompt is not
justified by those counts alone.

Four original exported GLBs pass independent validation with zero errors or
warnings. Final GPU result input hashes match their delivered GLBs. The hat
opening was independently viewed from below using the original GLB. Its patch's
exported midpoint row increased from 39.62 to 79.37 mm (about 2.003x); only patch
and stitch geometry changed. The island's revised bounds and fifteen protected
nodes are exactly unchanged. Both rendered edits returned automatic preservation
comparisons, and the agents additionally inspected them.

No original scored asset was repaired by the operator. These are evaluation
outputs, not accepted gallery exemplars. The hat demonstrates curved custom
geometry and a real opening. The island is a coarse stylized environment; its
stepped ramp and joins still require art/gameplay review. Valid GLB and contact
measurements do not establish a traversable, seamless environment.

### Findings and dispositions

- The hat guessed `latheGeo`; Discovery rejected it, suggested real contracts and
  the agent recovered. Keep exact selectors strict and word search forgiving.
- A custom hat mesh produced zero normals. Export QA caught it and the agent
  repaired the source. No helper/kernel regression was demonstrated.
- The island recovered from an inspection request lacking a numeric operation
  and a child-save request missing its required name. Existing schema diagnostics
  were sufficient; no special-case recovery path was added.
- The island's final prose called zero nearest-surface distances evidence of
  seamless joints. The returned limitation explicitly says zero includes touching
  **or crossing**, and excludes solid clearance/attachment guarantees. This is an
  observed model overclaim, not evidence that joints were certified. Its baseline
  final message also quoted 2,954 triangles while the final tool and independent
  placed-geometry count report 2,976. Retain receipts when accuracy matters.
- Setup succeeded, but required 54 response steps and read the installer. The
  isolated shell also inherited a Windows profile stub that referred to a missing
  file; commands still worked. This trial demonstrates usable setup after restart,
  not frictionless or strictly documentation-only setup. No global shell/profile
  change was made.

retired V1 evaluator. All now call V2. The complete collection rebuilds: 80 existing
programs, with no asset repairs. Original source/GLB pairs, poster provenance and

data delivery profile, not geometry/texture optimization or a game-readiness claim.

bytes match the HTTP resources and each other. The gallery's runtime link emits a
browser download event; its destination on disk was not inspected. The public
viewer now has native clip selection, pause/play and rest-pose controls. A peacock
clip was visually exercised there and in the local viewer from the runtime GLB
without supplying its sidecar. No new Blender/Unity player qualification is claimed.
The page had no observed JavaScript error; Three.js emitted dependency deprecation
and driver shader-precision warnings during the browser preview.

Site text now reflects current Node/Bun requirements, intent-based Discovery,
unrestricted authoring and historical showcase quality. Collection tags are filters,
not generation categories. Build, site typecheck and ten site-script tests pass.
