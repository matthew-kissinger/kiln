The owner requested ten new Antigravity assets, two Astra assets, and a few
OpenCode assets after the engine and existing gallery checks passed. This batch
adds fifteen independent authoring attempts. Only visually successful results
will enter the gallery; generating a file is not acceptance.

Every run starts in a separate workspace with a brief and the current project-local
skills. The installed engine is candidate `0d457e8f`, already checked on Windows
and Linux. Existing subscription or free model routes are used. No older models,
Omen, Claude, purchased fallback, or copied credentials are authorized.
