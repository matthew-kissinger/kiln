# Textured Boolean enclosure

Build a 1.2 × 0.8 × 0.7 m instrument enclosure with a rounded front, a large circular port, recessed rectangular service opening and three smaller cable passages. The cuts must pass through the shell where appropriate. Use distinct exterior and cut-surface materials and a visibly directional exterior surface treatment; preserve orientation through the cuts. Keep the interior inspectable.

ServiceAssembly is the removable side tray and its handles. serviceOffset controls its depth in the enclosure; rails and handles move together.

Define an animation named `ServiceMotion` lasting one second. The tray translates 0.25 m outward and returns over one second.

Use metres. Keep all geometry in the retained JavaScript program, name the inspection assembly exactly `ServiceAssembly`, and expose a numeric constant named `serviceOffset`. Do not import an existing asset or copy a finished example. Render and review the result using the tools available. Save a first source revision before any follow-up edit.

Review criteria: Assess real openings, shell thickness, interior visibility, material/UV consistency and tray alignment. CPU feedback cannot establish texture or PBR fidelity.
