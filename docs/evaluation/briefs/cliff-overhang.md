# Weathered cliff and overhang

Build a 5 m wide rock outcrop with a distinct overhang, an eroded recess beneath it, layered ledges and a narrow ledge walkway. Avoid a stack of disconnected rocks as the main form. Keep the underside readable and the walkway supported. Use restrained colours so shadows explain the shape.

ServiceAssembly is a small survey scanner on the ledge walkway. serviceOffset controls its position along the walkway, including its baseplate and safety guard.

Define an animation named `ServiceMotion` lasting one second. The survey scanner base translates 0.15 m along a short rail and returns over one second.

Use metres. Keep all geometry in the retained JavaScript program, name the inspection assembly exactly `ServiceAssembly`, and expose a numeric constant named `serviceOffset`. Do not import an existing asset or copy a finished example. Render and review the result using the tools available. Save a first source revision before any follow-up edit.

Review criteria: Assess coherent rock mass, true overhang, visible recess, useful surface variation and supported walkway.
