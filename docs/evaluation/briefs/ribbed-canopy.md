# Twisting ribbed canopy

Build a 6 × 4 m pedestrian canopy, about 3 m tall, with an asymmetric twisting roof. Show a clear change in roof orientation from one end to the other, twelve repeated structural ribs following the roof, two offset supports and a thin continuous roof surface. The roof must be more than a flat slab rotated as one object.

ServiceAssembly is a suspended maintenance light rail under the canopy. serviceOffset controls its lateral position; brackets and light housings move together.

Define an animation named `ServiceMotion` lasting one second. The light rail translates 0.25 m along its mounting track and returns over one second.

Use metres. Keep all geometry in the retained JavaScript program, name the inspection assembly exactly `ServiceAssembly`, and expose a numeric constant named `serviceOffset`. Do not import an existing asset or copy a finished example. Render and review the result using the tools available. Save a first source revision before any follow-up edit.

Review criteria: Assess roof twist, smooth surface, repeated rib alignment, asymmetric supports and underside attachments.
