# Asymmetric research hull

Build an 8 m research vessel with a broad working stern, narrow raised bow, a wheelhouse offset to port and an open starboard work deck. Give the hull a continuous curved side with a visible chine and different bow/stern sections. Include a stern sampling crane and readable deck railings. The silhouette must remain clear from bow, stern and below.

ServiceAssembly is the sampling crane carriage. serviceOffset controls its position along the stern deck track, including its footplate and cable guide.

Define an animation named `ServiceMotion` lasting one second. The crane carriage translates 0.4 m along its track and returns over one second; attached pieces must travel together.

Use metres. Keep all geometry in the retained JavaScript program, name the inspection assembly exactly `ServiceAssembly`, and expose a numeric constant named `serviceOffset`. Do not import an existing asset or copy a finished example. Render and review the result using the tools available. Save a first source revision before any follow-up edit.

Review criteria: Assess asymmetric deck plan, hull continuity, bow/stern distinction, railings and crane attachment.
