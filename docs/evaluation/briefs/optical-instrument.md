# Articulated optical instrument

Build a 1.5 m tall articulated observatory instrument: a stable tripod, offset horizontal translation carriage, a tilted optical tube, a focusing stage and a side eyepiece. Include brackets and fasteners joining the assemblies, including one attachment partly concealed by the carriage. Make the optical and mechanical axes legible without using text labels.

ServiceAssembly is the focusing stage with eyepiece and mounting bracket. serviceOffset controls its position along the optical tube; all attached parts move together.

Define an animation named `ServiceMotion` lasting one second. The complete carriage translates 0.3 m horizontally and returns over one second, carrying the tilted tube and focusing assembly.

Use metres. Keep all geometry in the retained JavaScript program, name the inspection assembly exactly `ServiceAssembly`, and expose a numeric constant named `serviceOffset`. Do not import an existing asset or copy a finished example. Render and review the result using the tools available. Save a first source revision before any follow-up edit.

Review criteria: Assess distinct axes, credible concealed attachment, coherent translation hierarchy and useful detail inspection.
