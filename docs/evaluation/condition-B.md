# Condition B

Call `kiln_list_primitives` without arguments for a compact overview. Use `name`
for one signature/example, `query` for an operation or `category` to browse; follow
`nextOffset` for more results. `capabilities:true` describes runtime limits.

For views, legacy preset/cells still work. Advanced captures use
`version:"kiln.capture.v1"` and `shots`. Choose exact part paths from the render
result, world/asset/part-relative orbit frames, explicit orthographic/perspective
cameras, context/isolation and grid/separate outputs when useful. Use the schema
for exact fields. Inspect the returned camera and view fidelity.

The new geometry helper family is not available. Ordinary source functions and
raw THREE geometry remain available. Use the advertised catalog as authority.
