# Condition A

`kiln_list_primitives` returns available helper signatures and examples. You may
filter by category. Use the legacy capture controls: preset grids and cells with
azimuth, elevation and padding. `kiln_inspect` provides legacy part views.

The new geometry helper family and advanced camera interface are not available.
Ordinary source functions and raw THREE geometry remain available. Use the
advertised schemas as the authority for inputs.
